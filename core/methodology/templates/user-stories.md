# User stories

Use this for the Analyze output `user-stories`. Name the users or personas affected. List stories with stable identifiers. Each in-scope story links to at least one acceptance criterion.

```markdown
# User stories

## Users
- <role or persona>: <who they are>

## Stories
### US-001 <short name>
- Story: As a <user>, I want <capability>, so that <outcome>
- Scope: in-scope | out-of-scope
- Criteria: AC-001
```
