## Assumptions
| Row | Assumption | Validation |
|---|---|---|
| ASM1 | A std-only GET-only loopback HTTP/1.1 server is feasible (thread per connection with hard cap, read/write timeouts, 8 KiB header cap, Connection: close). | Spike in Ideate; AC-013..AC-016 |
| ASM2 | std `RandomState` seeding yields at least 128 bits of token entropy when whitened with sha2 (not guaranteed by std; see Validation). | Validate on all three OSes; record in ADR (Q7). Caveat: std documents `RandomState` as randomly seeded but gives no cryptographic guarantee, and successive values in one thread differ only by an incremented key.
