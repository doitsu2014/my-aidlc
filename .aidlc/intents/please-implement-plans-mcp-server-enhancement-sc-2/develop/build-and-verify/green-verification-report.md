## Quality requirements verified

- Metadata only, no sensitive input stored (AC-002): field-for-field schema tests and a sentinel sweep (`ts027_sentinel_secrets_never_reach_the_store`); the threat review swept every tool argument and malformed frames. Intent ids are slugs of intent text and are disclosed (T2-10, fixed).
- MCP stdout carries protocol frames only; telemetry failure, panic and stall change nothing (AC-028): byte-identical stdout with telemetry on and off, failing-store, stalled and panicking writer tests, the stdout-write guard.
- Loopback only, read-only, browser-origin safe (AC-014, AC-015): exact Host, Origin, Sec-Fetch-Site; bearer token compared in constant-time style; GET only; no `Access-Control-*`; connection cap, head deadline and size cap (Observed in `monitor_http`).
- Nothing leaves the machine (AC-011): no remote URL, no inline script or style, CSP with Trusted Types (static tests, WU-021 fix).
- Existing CLI unchanged except scoped goldens (AC-027): goldens plus TS-025, TS-035, TS-037 procedures.
- Performance (Observed, release build, not committed): queue headroom no drop at 1k to 200k events/s for 2 s; rotation peak 54.96 MiB against the 50 MiB cap (soft, up to one open part); query on 62.9 MB, 132,574 events: cold 345 ms, warm 24 ms, RSS +79 MiB.
