# Implementation: WU-017 (Query engine)

- Status: Complete (build-and-verify, 2026-11-28). Cites FN-032, IF-017, CFG-011, ADR-026.
- New `rust-cli/telemetry/query.rs` (+ `pub mod query;` in `rust-cli/telemetry/mod.rs`): read-only query over `.aidlc/telemetry`. Strict parameter parsing (no `%`, unknown or duplicate keys, closed value sets, per-field id rules from the design pack: stage `^[a-z0-9-]{1,64}$`, session 32 lowercase hex, trace `<32hex>-<digits>` at most 64 chars); `range` default 3600 s, max 604800 (`range_too_large`); `limit` 1..200 default 50; hex cursor `v1|to|qhash16|last_ts|last_eventId` with frozen `to` (409 `cursor_stale` on any decode failure, mismatch or future `to`). Response shape is the final IF-017 list from the WU-016 review (ruling 5), including `summary.eventKinds` for all 8 kinds. Dedup by eventId, newest first with eventId tie-break; tolerance counters (`skippedLines`, `partialTails`, `unreadableFiles`, `expiredFiles`); absent store is an empty 200 and is not created; unsafe store is 503 `store_unavailable`; caps (512 files, 64 MiB, 250,000 events) give a partial 200 with `limitReached`; parse cache keyed by (path, length, mtime), memory only.
- Latency population (for IF-017): `summary.latency.n` counts distinct filtered `mcp.tool.completed` events with a non-null `durationMs`, every outcome included; nearest-rank p50/p95 at n >= 20, else `{n, insufficient: true}`. n equals `toolCalls` except for completions with a null duration.
- Conductor fixes from review nits: files whose mtime is up to 2 s before the window start are still read (coarse mtimes, clock steps); an overlong cursor (> 1024 chars) is now 409 `cursor_stale`, not 400; `path=` and `file=` keys added to the rejection test; the measurement test is Unix-only and removes its 60 MiB corpus.
